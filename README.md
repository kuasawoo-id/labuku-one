# LABUKU One — Frontend

Buku Kinerja ASN KUA · by Ahzani Labs · v2.2.0

Folder ini adalah tampilan (frontend) LABUKU One untuk GitHub Pages. Backend dan data berada di Google Apps Script dan Google Drive milik akun KUA.

## Struktur

```
index.html      halaman utama (harus di root repo)
css/style.css   tampilan
js/config.js    alamat backend (GAS_URL) ← satu-satunya file yang diubah per KUA
js/app.js       logika aplikasi
```
